# Thailand administrative divisions

`provinces.json`, `districts.json`, and `subdistricts.json` are copied from [thailand-geography-data/thailand-geography-json](https://github.com/thailand-geography-data/thailand-geography-json), under the included MIT License.

The dataset provides Thai names and numeric province, district, and subdistrict codes. These are formatted to 2, 4, and 6 digits respectively, matching `pro_code`, `amp_code`, and `tam_code` in the companion GeoJSON boundaries.

The source lists 77 provinces, 928 districts, and 7,436 subdistricts. Postal code values are supplied by the source data and are displayed when present.
