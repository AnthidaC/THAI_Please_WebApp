# Thailand administrative boundary data

The province, district, and subdistrict GeoJSON files in this directory are from [OpenGISData-Thailand](https://github.com/chingchai/OpenGISData-Thailand), which attributes the administrative boundaries to Thailand's Department of Provincial Administration (DOPA).

The source repository states that the boundary dataset is licensed under [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). A copy of the license text is included as `CC-BY-4.0.txt`. The source repository also documents its source fields, code formats, and attribution requirements in its [README](https://github.com/chingchai/OpenGISData-Thailand/blob/master/README.md).

The accompanying selector data in `../thai-address/` comes from [Thailand Geography JSON](https://github.com/thailand-geography-data/thailand-geography-json) under the MIT License. Province, district, and subdistrict codes use the same 2-, 4-, and 6-digit formats as the boundary properties.
